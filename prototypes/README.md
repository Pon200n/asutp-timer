# Прототипы

Здесь лежат HTML-прототипы интерфейса. Порядок работы:

1. Я делаю прототип в этой папке и кладу ссылку на файл.
2. Вы открываете его в браузере (можно на телефоне) и правите: цвета, размеры,
   тексты, порядок элементов.
3. Говорите «готово» — я переношу утверждённый вид в код приложения
   (для нативных экранов — в Java, для веб-частей — в `www/js` и `www/css`).

**Прототипы не попадают в сборку APK** — папка лежит рядом с `www/` и
`android/`, в `assets/` не копируется.

## Как открыть

- Локально: двойной клик по файлу, или «Live Server» в VS Code.
- На телефоне: `python -m http.server` в корне репозитория и адрес
  `http://<ip компьютера>:8000/prototypes/<файл>/index.html`.
- Файл можно открыть и напрямую из папки — всё работает на локальных
  ресурсах, без сервера.
